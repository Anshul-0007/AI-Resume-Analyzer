# AI Resume Analyzer 📄

## About the Project
AI Resume Analyzer is a Python-based web application that analyzes PDF resumes according to a given job description.

## Features
- Upload PDF Resume
- Extract Text from PDF
- Detect Resume Skills
- Calculate Resume Matching Score
- Identify Missing Skills

## Technologies Used
- Python
- Streamlit
- PyPDF2
- Scikit-learn
- TF-IDF
- Cosine Similarity
- Regular Expressions

## How to Run

Install required libraries:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

## Project Files
- app.py – User Interface
- resume_analyzer.py – Resume Analysis Logic
- requirements.txt – Required Libraries
